# 게임 브리프

## 현재 상태

`Signal Courier`는 최종 게임 콘셉트가 아니라 하네스와 플레이 검증 루프를 증명하는 교체 가능한 레퍼런스 수직 조각이다.

## 플레이어 판타지

붕괴 직전의 네트워크에서 제한 시간 안에 흩어진 신호 노드를 회수하는 기민한 전달자.

## 핵심 루프

1. 가장 가까운 미수집 노드를 판단한다.
2. 제한 시간과 이동 거리를 고려해 경로를 선택한다.
3. 노드에 접촉해 회수한다.
4. 모든 노드를 회수하거나 시간이 끝날 때까지 반복한다.

## 현재 성공·실패 조건

- 성공: 45초 안에 5개 노드를 모두 수집한다.
- 실패: 미수집 노드가 남은 상태에서 제한 시간이 0이 된다.

## 다음 제품 결정

본격 제작 전에 소유자가 장르, 카메라, 한 판 길이, 타깃 플랫폼, 아트 방향을 확정한다. 결정 후 이 문서를 실제 게임 브리프로 교체하고 `ops/CHARTER.md`의 성공 기준을 갱신한다.
