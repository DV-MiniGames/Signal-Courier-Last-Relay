# SIGNAL COURIER: LAST RELAY 게임 브리프

## 제품 한 줄

붕괴하는 도시망에 중계기 사슬을 놓고 데이터를 회수한 뒤, 10분 안에 살아서 귀환하는 싱글 플레이 2D 탑다운 액션·경로 설계 로그라이트다.

## 플레이어와 플랫폼

- 대상: 짧고 완결된 액션 세션에서 경로 최적화와 위험 관리를 즐기는 PC 인디 게임 플레이어
- 플랫폼: 최신 Chromium 계열 데스크톱 웹
- 입력: 키보드와 마우스 우선
- 한 판: 활성 플레이 최대 10분, 목표 중앙값 7~9분

## 플레이어 판타지

플레이어는 강한 전투원이 아니라 총격 속에서도 연결 경로를 만들고 임무를 끝내는 최후의 신호 전달자다. 전투는 적을 섬멸하기 위한 목적이 아니라 중계기 설치, 패킷 업로드, 귀환에 필요한 시간을 사는 수단이다.

## 디자인 기둥

1. 경로가 곧 빌드다. 중계기 배치가 업로드 지점, 안전 구역, 적의 표적, 귀환 경로를 함께 바꾼다.
2. 전투는 시간을 산다. 불필요한 처치보다 목표 수행과 이탈이 더 좋은 선택일 수 있다.
3. 안전한 성공과 욕심의 경계가 선명하다. 패킷 2개부터 탈출할 수 있고, 3개와 과부하 데이터는 더 큰 위험을 요구한다.
4. 10분 안에 읽고 결정하고 다시 도전한다. 실패 이유는 난수보다 경로와 판단으로 설명되어야 한다.

## 핵심 루프

1. 본부에서 무기, 유틸리티, 중계기 모듈을 고른다.
2. 패킷 후보와 소켓을 읽고 중계기 사슬을 확장한다.
3. 패킷을 회수해 연결된 중계기에서 업로드한다.
4. 적을 밀어내고 끊긴 링크를 수리하며 귀환 경로를 유지한다.
5. 패킷 2개 이후 부분 탈출 또는 세 번째 패킷·과부하 데이터 도전을 선택한다.
6. 본부에서 8초간 추출 신호를 유지하고 결과와 경로를 확인한다.

## 성공·실패 조건

- 실패: 패킷을 2개 미만 업로드했거나 10분 안에 추출하지 못한다.
- 부분 전달: 패킷 2개 이상을 업로드하고 추출한다.
- 완전 전달: 패킷 3개를 업로드하고 추출한다.
- 업로드한 기본 기록 조각은 실패해도 보존하고, 과부하 데이터와 성공 보너스는 탈출해야 보존한다.

## MVP 경계

MVP는 손으로 설계한 맵 1개, 시드 3개 이상, 적 4종, 중계기 3개, 패킷 3개, 부분·완전 탈출, 10분 디렉터, 수평형 해금, 로컬 저장을 포함한다. 멀티플레이, 백엔드, 절차 생성 지형, 캠페인, 제작·상점 경제, 다중 재화, 장비 희귀도, 모바일은 포함하지 않는다.

상세 수치, 시스템, 범위, 성공 지표와 레퍼런스 근거는 [게임 디자인 확정안](../preproduction/GAME-DESIGN-PROPOSAL.md)을 따른다. 장르, 카메라, 런 길이, 플랫폼 또는 아트 방향 변경은 별도 ADR이 필요하다.

## 현재 플레이 가능한 3구역 조각

손으로 설계한 `외곽 회선(105초) → 교차 구역(90초) → 붕괴 코어(75초)`를 연속 공략한다. 각 구역은 본부·소켓·패킷·엄폐·적 배치가 다르며, 후반으로 갈수록 적 수, 필수 처치 수, 이동 속도, 사격 빈도와 피해가 상승한다. 엄폐물은 이동과 투사체를 실제로 막고, 업로드 시 남은 시간·처치 보너스를 누적 점수로 환산한다.

플레이어는 이동·대시·과열식 조준 사격·EMP로 공간을 확보하고 중계기를 설치한 뒤 패킷을 회수해 업로드한다. 사수 탄환이 중계기를 맞히면 청록 실선이 자홍 파선 교란으로 바뀌고 내구도 0에서 회색 긴 파선으로 단절되며, 수리하면 안전 반경·대시 충전·무기 냉각 보조가 복귀한다. 사격·명중·처치·피격·EMP·중계기·업로드는 서로 다른 Canvas FX와 절차 합성 음향으로 구분된다.

이 조각은 10분 전체 런이나 최종 밸런스가 아니라 “전투로 공간을 사고 연결 경로를 만들어 임무를 끝낸 뒤 더 높은 압력에 재도전한다”는 핵심 가설을 검증한다.
