# 게임 검증 규약

## 정적 검증

```bash
npm run check
npm run build
```

개발 서버가 `http://127.0.0.1:4173`에서 실행 중이면 전체 상태 전이를 한 번에 검증할 수 있다.

```bash
npm run test:game
```

다른 주소는 `GAME_URL` 환경 변수로 지정한다.

## 플레이 검증

개발 서버를 실행하고 Codex의 `develop-web-game` Playwright 클라이언트로 짧은 입력 버스트를 수행한다.

검증 순서:

1. 메뉴 스크린샷과 `mode=menu` 상태를 확인한다.
2. `Enter` 후 `mode=playing`을 확인한다.
3. 이동 입력 후 플레이어 좌표가 예상 방향으로 변하는지 확인한다.
4. 노드 접촉 후 화면에서 사라지고 `score`와 `remainingBeacons`가 함께 갱신되는지 확인한다.
5. 일시정지, 재시작, 성공, 시간 초과를 각각 독립 시나리오로 검증한다.
6. 최신 스크린샷을 직접 열어 잘림, 대비, 누락을 확인한다.
7. 새 콘솔 오류가 없는지 확인한다.

산출물은 `artifacts/` 아래에 두고 Git에는 포함하지 않는다. 재현 명령과 핵심 관찰은 해당 작업 기록과 `progress.md`에 남긴다.
