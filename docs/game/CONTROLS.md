# 게임 컨트롤

| 입력 | 동작 | 사용 상태 |
|---|---|---|
| `Enter` | 게임 시작 | 메뉴 |
| `WASD`, 방향키 | 플레이어 이동 | 플레이 중 |
| 마우스 이동 | 조준 | 플레이 중 |
| 마우스 왼쪽 버튼 | 펄스 블래스터 사격 | 플레이 중 |
| `Space` | 진행 방향 또는 조준 방향으로 대시 | 플레이 중 |
| 마우스 오른쪽 버튼 | 근거리 EMP 펄스 | 플레이 중 |
| `E` 길게 누르기 | 중계기 설치, 패킷 업로드, 오프라인 중계기 수리 | 플레이 중, 대상 반경 안 |
| `P` | 일시정지/계속 | 플레이 중, 일시정지 |
| `R` | 현재 런 재시작 | 모든 상태 |
| `F` | 전체 화면 전환 | 모든 상태 |
| `Escape` | 전체 화면 종료 | 전체 화면 |

새 입력을 추가하거나 의미를 바꾸면 시작 화면, 이 문서, 자동 조작 시나리오를 같은 작업에서 함께 갱신한다.

M1 목표 흐름은 `중앙 소켓에서 E 1초 설치 → 우측 패킷 접촉 회수 → 활성 중계기에서 E 3초 업로드`다. 중계기가 단절되면 같은 위치에서 `E`를 2초 유지해 수리하고, 교란 중에는 EMP로 즉시 정상화할 수 있다.
