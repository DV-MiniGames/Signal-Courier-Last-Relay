## 확인 규칙

- 중요한 사건은 화면, 소리, 텍스트 중 두 채널 이상으로 알린다.
- 색만으로 상태를 전달하지 않는다.
- VFX는 원인 지점과 다음 행동을 가리지 않는다.
- 반복 사건은 동시 발음과 음량 상한을 정한다.
- reduced-motion과 음소거에서도 게임 진행이 가능해야 한다.
