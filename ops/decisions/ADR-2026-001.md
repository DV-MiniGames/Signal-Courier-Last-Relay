# ADR-2026-001: 첫 게임 런타임 기준선

- 상태: Accepted
- 결정일: 2026-08-30
- 결정자: 프로젝트 부트스트랩 작업
- 관련 작업·이슈: TASK-20260830-01

## 맥락

최종 게임 장르가 정해지지 않은 상태에서 운영 하네스가 실제 게임 제작과 검증을 수행할 수 있음을 증명해야 한다. 특정 엔진에 장기 결합하지 않으면서 빠르게 실행 가능한 브라우저 수직 조각이 필요하다.

## 선택지

| 선택지 | 장점 | 단점 | 위험 |
|---|---|---|---|
| Vite + TypeScript + Canvas 2D | 작고 빠름, 브라우저 자동화 용이, 엔진 종속성 없음 | 씬·물리 도구를 직접 구성 | 게임 복잡도 증가 시 구조 확장 필요 |
| Phaser | 게임 기능과 생태계가 풍부 | 초기 종속성과 추상화 비용 | 최종 장르와 맞지 않을 수 있음 |
| Godot | 강력한 에디터와 런타임 | 웹 자동화와 에이전트 텍스트 상태 연결 비용 | 현재 하네스 검증 범위를 초과 |

## 결정

첫 기준선은 Vite 8, TypeScript, Canvas 2D를 사용한다. SIGNAL COURIER: LAST RELAY 코드는 최종 제품 기반이 아니라 하네스의 실행·상태·화면 검증 계약을 증명하는 교체 가능한 수직 조각으로 취급한다.

## 결과

- 기대 효과: 최소 의존성으로 즉시 실행하고 Playwright로 입력과 화면을 검증한다.
- 감수하는 단점: 실제 게임 방향이 정해지면 엔진 선택과 코드 구조를 다시 결정할 수 있다.
- 되돌리기 조건: 최종 콘셉트가 3D, 에디터 중심 레벨 제작, 복잡한 물리를 핵심 요구로 확정한다.
- 재검토일 또는 재검토 신호: TASK-20260830-02 완료 시.
