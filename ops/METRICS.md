# 운영 지표

지표는 사람 평가가 아니라 제작 시스템의 병목을 찾는 관찰값이다. 매주 하나의 개선 지표만 선택한다.

## 이번 주 초점

- 대상 주: 2026-08-30 시작 주
- 개선할 지표: 플레이 변경의 검증 증거율
- 현재값: 100% (플레이 변경 5/5)
- 목표 또는 기대 방향: 타입 검사, 빌드, 입력 상태, 텍스트 상태, 스크린샷 증거 100% 유지
- 선택 이유: 게임은 코드 성공보다 실제 플레이 결과가 중요하며 초기 하네스에서 가장 먼저 고정할 계약이다.

## 주간 추세

| 주 | Done | Lead time 중앙값 | Blocked ratio | Rework rate | 플레이 증거율 | Learning yield | Skill reuse |
|---|---:|---:|---:|---:|---:|---:|---:|
| 2026-08-30 | 6 | 당일 | 0% | 33% (2/6) | 100% (5/5) | 100% (6/6) | 100% (6/6) |

## 정의

- **Done**: 해당 주에 Definition of Done을 충족한 작업 수
- **Lead time 중앙값**: 작업별 `Done 시각 - Doing 시작 시각`의 중앙값
- **Blocked ratio**: 전체 리드타임 중 외부 의존성으로 진행하지 못한 시간 비율
- **Rework rate**: Done 이후 재작업이 발생한 작업 수 / Done 작업 수
- **플레이 증거율**: 플레이 변경 중 자동 입력, 상태 JSON, 스크린샷을 모두 남긴 작업 비율
- **Learning yield**: 유효 학습 후보 수 / Done 작업 수
- **Skill reuse**: 기존 스킬을 사용한 작업 수 / 전체 시작 작업 수
