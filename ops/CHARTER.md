# 프로젝트 헌장

## 프로젝트 목적

에이전트와 사람이 게임의 목표, 실행 작업, 검증 증거, 학습을 하나의 저장소에서 이어 갈 수 있는 재현 가능한 제작 워크스페이스를 구축한다. 첫 마일스톤은 최종 장르를 확정하는 것이 아니라, 작은 플레이 수직 조각을 빠르게 만들고 실제 입력과 화면으로 검증하는 능력을 증명한다.

## 대상 사용자

- 주요 사용자: 게임 소유자와 구현 에이전트
- 현재 문제: 기획, 구현, 테스트, 학습 기록이 분리되어 다음 세션이 같은 판단을 반복한다.
- 기대 변화: 새 작업자가 10분 안에 현재 목표와 다음 작업을 파악하고, 로컬 빌드와 플레이 검증을 재현한다.

## 성공 기준

| 지표 | 현재값 | 목표값 | 측정 주기 | 데이터 출처 |
|---|---:|---:|---|---|
| 신규 세션 기준선 파악 시간 | 미측정 | 10분 이하 | 마일스톤 | 작업 기록 |
| `check`/`build` 성공률 | 기준선 없음 | 100% | 변경마다 | 명령 결과 |
| 플레이 변경의 스크린샷·상태 증거율 | 기준선 없음 | 100% | 변경마다 | 작업 기록 |

## 범위

### 포함

- Hermes 운영 루프를 게임 제작에 맞게 적용
- Vite/TypeScript/Canvas 기반 실행 가능한 레퍼런스 수직 조각
- 결정론적 시간 진행, 텍스트 상태, Playwright 플레이 검증 계약
- 게임 브리프, 조작, 아키텍처, 작업·결정·메모리 문서

### 포함하지 않음

- 최종 게임 장르와 상업 범위 확정
- 백엔드, 계정, 결제, 멀티플레이
- 최종 아트·사운드 에셋 제작
- 배포 인프라와 스토어 출시

## 제약

- 일정: 첫 기준선은 한 작업 안에서 실행·검증 가능해야 한다.
- 비용: 유료 서비스 없이 로컬에서 재현 가능해야 한다.
- 기술: Node.js 20.19+ 또는 22.12+, 최신 브라우저, 키보드 입력을 기준으로 한다.
- 보안·법률: 라이선스가 확인되지 않은 외부 에셋을 포함하지 않는다.
