# 프로젝트 헌장

## 프로젝트 목적

Hermes 운영 하네스를 기반으로 `SIGNAL COURIER: LAST RELAY`를 제작한다. 제품은 붕괴하는 폐도시에서 중계기 사슬을 구축하고 데이터를 회수한 뒤 10분 안에 귀환하는 싱글 플레이 2D 탑다운 액션·경로 설계 로그라이트다. 기획, 구현, 검증 증거와 학습을 한 저장소에 남겨 사람이 바뀌어도 같은 기준에서 제작을 이어 간다.

## 대상 사용자

- 주요 플레이어: 짧은 PC 액션 세션에서 경로 최적화, 위험 관리, 반복 숙련을 즐기는 인디 게임 플레이어
- 제작 사용자: 게임 소유자와 역할별 에이전트
- 기대 경험: 신규 플레이어가 60초 안에 첫 목표를 이해하고, 10분 안에 부분 성공·완전 성공·실패 중 하나로 끝나는 의미 있는 런을 경험한다.

## 성공 기준

| 지표 | 현재값 | MVP 목표 | 측정 주기 | 데이터 출처 |
|---|---:|---:|---|---|
| 첫 패킷 목적 이해 | 미측정 | 신규 플레이어 80%가 60초 안에 첫 패킷으로 이동 | M1/M3 플레이테스트 | 이벤트 로그·관찰 |
| 첫 연결 성공 | 미측정 | 80%가 2분 안에 설치·연결·업로드 수행 | M1/M3 플레이테스트 | 상태 로그·화면 녹화 |
| 경로 선택 체감 | 미측정 | 70%가 중계기 위치 영향에 4/5 이상 응답 | M2/M3 플레이테스트 | 설문·경로 로그 |
| 런 길이 | 45초 하네스 기준선 | 중앙값 7~9분, 최대 10분 | M2 이후 | 런 이벤트 |

## 범위

### 포함

- 손으로 설계한 폐도시 맵 1개와 검증 가능한 시드
- 이동, 대시, 조준 사격, EMP, 적 4종
- 중계기 설치·연결·교란·수리와 패킷 업로드
- 부분/완전 탈출, 10분 하드 캡, 시간·진척 기반 디렉터
- 런 내 강화, 수평형 로컬 메타 해금, 변형 계약
- 시작·HUD·일시정지·결과 화면, 로컬 저장, 접근성 기본 설정
- 결정론적 시간, 텍스트 상태, 실제 입력과 스크린샷 기반 회귀 검증

### 포함하지 않음

- 멀티플레이, 계정, 백엔드, 클라우드 저장, 결제와 순위표
- 절차 생성 지형, 캠페인 월드맵, 장시간 분기 서사
- 제작, 상점 경제, 다중 재화, 장비 희귀도, 반복 스탯 성장
- 차량·화물 물리, 탄약·허기·슬롯형 인벤토리
- 모바일·콘솔 정식 지원, 최종 성우·라이선스 음악

## 제작 운영 원칙

- 비코드 기획·조사·디자인·문서화는 Codex 역할 에이전트가 수행한다.
- 코드 구현은 Claude 접근이 정상일 때 Claude 역할 에이전트를 우선한다. 접근할 수 없으면 Codex가 구현을 이어 간다.
- Gemini는 사용하지 않는다.
- 코디네이터는 작업 분해, 충돌 방지, 결과 통합, 검증과 보드 갱신을 담당한다.
- 외부 에셋은 원출처, 라이선스, 상업 이용·수정·귀속 조건을 기록한 뒤 저장소에 넣는다.

## 제약

- 비용: 사전 제작과 MVP는 무료·오픈소스 도구와 재배포 가능한 에셋을 우선한다.
- 기술: 최신 Chromium 데스크톱 웹, 키보드+마우스, Node.js 20.19+ 또는 22.12+를 기준으로 한다.
- 품질: 플레이 가능 빌드는 `render_game_to_text`와 `advanceTime` 계약을 유지한다.
- 법률: 라이선스가 확인되지 않은 외부 에셋과 AI 생성물의 불명확한 학습·배포 권리를 포함하지 않는다.
- 범위: 장르, 카메라, 10분 런, 플랫폼, 아트 방향 변경은 별도 ADR과 일정 재산정이 필요하다.
