# SIGNAL COURIER: LAST RELAY

> 마지막 중계기를 세우고, 붕괴한 도시의 신호를 되살려라.

## 마지막 신호를 연결하라

도시는 단절됐고 중계기는 적의 공격에 노출되어 있습니다. 적을 모두 쓰러뜨리는 것보다 제한 시간 안에 안전한 경로를 만들고 패킷을 전달하는 것이 중요합니다.

1. 건물을 엄폐물로 삼아 중계기 소켓까지 진입합니다.
2. 중계기를 설치하고 패킷을 회수합니다.
3. 몰려오는 적과 교란을 버티며 패킷을 업로드합니다.
4. 더 좁은 동선과 강한 위협이 기다리는 다음 구역으로 이동합니다.

세 구역을 모두 연결하면 도시망이 복구됩니다. 뒤로 갈수록 제한 시간은 짧아지고, 필수 전투와 적의 압박은 강해집니다.

## 직접 플레이하기

Node.js 20.19+ 또는 22.12+와 최신 Chromium 계열 브라우저가 필요합니다.

```bash
npm ci
npm run dev
```

터미널에 표시된 주소를 열고 `Enter`를 누르면 시작합니다.

## 조작

| 입력 | 동작 |
|---|---|
| `WASD` / 방향키 | 이동 |
| 마우스 이동 / 왼쪽 버튼 | 조준 / 사격 |
| `Space` | 대시 |
| 마우스 오른쪽 버튼 | EMP |
| `E` 길게 누르기 | 중계기 설치·수리·패킷 업로드 |
| `Enter` | 시작·다음 구역 |
| `P` | 일시정지 |
| `R` | 전체 런 재시작 |
| `F` / `Escape` | 전체 화면 전환 / 종료 |

## 현재 빌드

- 서로 다른 지형과 적 배치를 가진 3개 구역
- 사격 과열, 대시, EMP와 엄폐 전투
- 중계기 설치·교란·수리와 패킷 업로드
- 구역별 제한 시간, 누적 점수와 최종 결과 화면
- 키보드와 마우스로 플레이하는 데스크톱 웹 프로토타입

전체 검증은 `npm run verify`로 실행할 수 있습니다.
